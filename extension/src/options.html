Chrome MCP connection

Public connections are authenticated by Cloudflare Access. The extension no longer stores or sends a PSK. Sign in once through the protected Unified MCP hostname so Cloudflare can set its authorization cookie, then connect over WSS.

For cross-origin extension WebSockets, keep the Cloudflare Access application cookie SameSite setting at None. Cloudflare terminates WSS; the local Unified MCP service itself listens only on HTTP.
